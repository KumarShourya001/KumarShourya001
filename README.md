#### [Vaidya.AI — Edge-First Ambient Clinical Scribe](https://github.com/KumarShourya001/VAIDYA.AI)

Records a doctor-patient consultation, transcribes it locally, and turns it into a structured clinical note plus **FHIR R4B** resources. All inference runs on the machine — audio never leaves it.

- **Local pipeline:** faster-whisper for speech, Ollama for note generation, switchable between `llama3.2:3b` (fast) and `qwen2.5:7b` (better clinical read) per request
- **Browser fallback:** where no GPU host exists, whisper-tiny runs in-browser via transformers.js and a 1.5B model via WebGPU — so the privacy claim holds on the web too
- **Patient portfolio:** conditions, allergies, medications, appointments behind auth, plus an emergency card readable without sign-in
- **Grounded assistant:** chatbot scoped to a single patient's record; refuses to recommend or alter medication, escalates on emergency symptoms
- Split deploy — React/Vite frontend, containerised FastAPI backend, Postgres or SQLite

`FastAPI` `React` `faster-whisper` `Ollama` `FHIR R4B` `SQLAlchemy` `Docker`
